# Complete TTS Flow (MongoDB → ElevenLabs → PulseAudio → Meeting)

## Step 0 — Brain inserts TTS task

Brain Agent writes to MongoDB:

Collection: `tts_queue`

```json
{
  "_id": "uuid",
  "session_id": "sess_123",
  "text": "Tell me about your experience with microservices.",
  "status": "pending",
  "created_at": 1700000000
}
```

This insert triggers MongoDB Change Stream.

---

# Step 1 — TTS Service receives Change Stream event

Your TTS Service is listening:

```python
change_stream = db.tts_queue.watch([
  {"$match": {"operationType": "insert"}}
])
```

MongoDB sends event instantly:

```json
{
  "operationType": "insert",
  "fullDocument": {
    "_id": "uuid",
    "text": "Tell me about your experience with microservices."
  }
}
```

Latency: ~5–20 ms

---

# Step 2 — TTS Service marks task as "playing"

Update MongoDB:

```json
{
  "status": "playing",
  "started_at": 1700000001
}
```

Why?

So Control / Brain knows TTS is speaking.

---

# Step 3 — TTS Service sends text to ElevenLabs Streaming API

Request:

```http
POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}/stream
```

Body:

```json
{
  "text": "Tell me about your experience with microservices.",
  "model_id": "eleven_multilingual_v2"
}
```

ElevenLabs starts generating audio immediately.

---

# Step 4 — ElevenLabs returns audio stream in chunks

Example stream:

```text
chunk 1 → audio bytes
chunk 2 → audio bytes
chunk 3 → audio bytes
...
```

Latency to first chunk:

```text
~200–400 ms
```

This is critical for real-time.

---

# Step 5 — TTS Service receives audio chunks

Your code loop:

```python
for chunk in response.iter_content(chunk_size=4096):
```

Each chunk is raw audio.

---

# Step 6 — TTS Service writes chunk to PulseAudio virtual microphone

Write to:

```text
virtual_mic
```

Using sounddevice or PyAudio:

```python
stream.write(audio_chunk)
```

Now audio enters PulseAudio.

---

# Step 7 — PulseAudio routes audio into browser microphone

Flow:

```text
TTS Service
   ↓
PulseAudio virtual_mic
   ↓
Browser microphone input
   ↓
Meeting
   ↓
Candidate hears AI speaking
```

No physical speaker involved.

Silent operation.

---

# Step 8 — Browser sends audio to meeting via WebRTC

Browser automatically sends microphone audio.

No extra work needed.

---

# Step 9 — TTS continues streaming until complete

Loop continues:

```python
receive chunk
write chunk
receive chunk
write chunk
```

Until finished.

---

# Step 10 — TTS Service marks task completed

Update MongoDB:

```json
{
  "status": "completed",
  "completed_at": 1700000003
}
```

---

# Step 11 — Control Service detects TTS finished

Control Service may subscribe to MongoDB or Redis.

State changes:

```text
SPEAKING → LISTENING
```

# Important: Interrupt Flow (when candidate interrupts)

If MongoDB receives interrupt:

Collection:

```text
tts_interrupt
```

TTS immediately:

```python
stream.stop()
```

Stops PulseAudio.

Meeting stops hearing AI.
